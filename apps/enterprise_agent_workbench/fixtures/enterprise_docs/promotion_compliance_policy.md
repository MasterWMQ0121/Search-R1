# Promotion Compliance Policy

## Truthful promotion claims

Campaign copy and recommendations must not promise guaranteed returns or use
unsupported performance claims. Supporting data must identify its reporting
period and campaign.

## Restricted changes

An operator or administrator may propose a promotion change. Side-effecting
actions require a human approval decision and an idempotency key before the
local business API may execute them.

## Records and retention

Store concise audit facts and explicit user preferences only. Do not place
credentials, access tokens, hidden model reasoning, or unrestricted database
rows in long-term memory or execution traces.
